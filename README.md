# Cambridge One → PDF

تعديل بسيط لتطبيق **Cambridge One Desktop** — كل كتاب بتنزّله بيتحوّل تلقائيًا لملفي PDF (سريع + جودة عالية) مع روابط وفهرس شغّالين.

## خطوات التشغيل

1. ثبّت **Cambridge One Desktop App** الرسمي.
2. ثبّت **Node.js** من https://nodejs.org
3. نزّل هالمشروع (Code → Download ZIP) وفك الضغط.
4. أغلق التطبيق لو شغال.
5. شغّل `patch.bat` (دبل-كليك).
6. افتح التطبيق، سجّل دخولك، ونزّل أي كتاب.

## مكان التخزين

الكتب والـ PDFs بتنزل هون:

```
%APPDATA%\CambridgeOne\books\<رمز الكتاب>\
```

وفي كل مجلد كتاب رح تلاقي:

- `<رمز>.pdf` — نسخة سريعة وخفيفة
- `<رمز>-hq.pdf` — نسخة جودة عالية

## للتراجع

شغّل `unpatch.bat` — بيرجّع التطبيق الأصلي.

---

*لأغراض تعليمية فقط. مبني على CambridgeOne 2.54.0 — لو طلعت رسالة "unsupported version" حدّث الأداة.*
